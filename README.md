# AppVault v2.1 開發總管

## v2.1 介面與操作優化
1. **手機桌面名稱粗體置首（`phoneAppLabel`）**：
   - 自動讀取手機已安裝 App 的顯示名稱（例如手機桌面的粗體名稱），並置於每張卡片最開頭以粗體顯示（若手機未安裝則顯示記錄名稱）。
2. **「全選／部分選取」一鍵批次刪除**：
   - 主畫面與多選列新增「全選／取消全選」按鈕，長按任一卡片或點多選按鈕即可勾選全部或部分 App 一次過移至回收筒。
3. **精簡「需要更新」勾選設計**：
   - 手機與 Gemini 版本**不吻合**時：顯示未勾選格仔 **`☐ 需要更新`**，點擊即可手動確認已更新並打勾。
   - 兩者**吻合**（或已手動打勾確認）時：只顯示簡潔的綠色 **`☑`** 勾號，不再重複顯示「已最新／吻合」文字標籤，介面更清爽易看。
