# AppVault v2.2 開發總管

## v2.2 介面與摺疊／展開統一排版升級
1. **摺疊機開合統一排版與放大清晰字級**：
   - 在 Galaxy Z Fold 7 展開與合埋（外屏）狀態下均採用一致的單欄／寬鬆卡片比例（不硬擠雙欄壓扁字體），讓「建立日期」、版本號與按鈕全部維持清楚放大字級，絕不出現直排擠壓。
2. **橫向標籤自動換行（FlowRow）**：
   - 卡片內的 `Gemini v...`、`手機v...`、分類標籤與建立日期改用自適應 `FlowRow` 橫向流式排列，寬度不足時自動順暢落到下一行，保持視覺整齊統一。
3. **移除重複標籤＋啟動自動抓取手機實裝 APK 圖示與名稱**：
   - 移除重複多餘的「最新／待確認」徽章，只保留單一清晰的「☑ 勾選」或「☐ 需要更新」；每次開啟 App 不論是否填寫 Gemini API Key，均自動掃描手機已安裝 APK 的真實圖示、桌面名稱與版本號。
4. **搜尋與篩選列單行清爽收納**：
   - 搜尋框維持精簡單行高度，為 App 清單騰出更多可視空間。
