# AppVault v1.8 開發總管（全建議實裝旗艦版）

Android 原生 Kotlin（Jetpack Compose + Material 3）與獨立可安裝桌面網頁版（PWA）雙架構自製 App 中控台，支援窄屏手機、Galaxy Z Fold 7 展開雙欄、平板與桌面瀏覽器。

## v1.8 全方位升級亮點

### 1. 無感自動化同步
- **防抖自動雙向同步＋時間戳智慧合併**：開啟 App 自動從 Gist 拉取並以每個 App 的 `updatedAt` 智慧合併（手機與電腦同時改不同 App 也不互覆蓋）；任何修改後靜默等待 3 秒自動上傳。
- **Android 系統分享選單（Share Target）直連 Gemini**：在 Gemini 直接按「分享 → AppVault」，自動跳出解析確認視窗寫入新 App 或更新版本。
- **GitHub Repo 一鍵全抓＋Actions 編譯燈號**：貼上 Repo 連結一鍵抓回最新 Release、專案介紹與最近一次 GitHub Actions 編譯狀態（🟢 成功／🟡 編譯中／🔴 失敗）。
- **背景定時檢查＋升級通知（WorkManager）**：每日背景比對手機實裝 APK 與最新記錄／GitHub 版本，有待升級項目自動發系統通知。

### 2. 自製 App 中控台體驗
- **點小圖示直接啟動 App＋長按快捷選單**：點主頁卡片的 APK 真實小圖示直接啟動該 App；長按圖示顯示快捷選單（啟動／開 Actions／複製同步 ID／開 Gist）。
- **版本號一鍵進位膠囊**：支援 `+0.0.1`、`+0.1`、`+1.0` 一鍵升版，自動寫入歷史時間軸並重置安裝勾選。
- **「今日待處理」專注視圖（Focus View）**：自動彙整未發布 GitHub、手機未裝最新、缺同步 ID 或編譯失敗的項目，逐一處理即時清零。
- **跨裝置設定加密 QR 一鍵遷移**：以個人 PIN 碼將 GitHub Token、Gist ID 與 Gemini API Key 做 AES-256-GCM 加密打包成 QR Code 或密文，換機／開電腦版掃一次即完成所有連線設定。

### 3. 人性化操作與大屏手感
- **左右滑動手勢**：右滑即時切換「手機已裝最新」（配震動回饋），左滑快速移入回收筒並附 5 秒 **「復原 (Undo)」** 提示條。
- **雙欄自動儲存（Auto-Save）**：Galaxy Z Fold 7 展開與桌面版編輯欄位自動防抖儲存。
- **長按多選批次操作**：長按卡片進入多選模式，一次批次改分類、標記已發布／已安裝或移入回收筒。
- **摺疊開合記憶狀態**：完整記憶排序、分類、視圖模式、強調色與篩選設定。

### 4. 美化介面與視覺質感
- **極簡緊湊／完整詳情雙模式切換**：預設極簡模式讓十多款 App 一覽無遺，隨時一鍵切換完整詳情。
- **依 APK 圖示動態取色色帶**：自動擷取每個 APK 真實圖示主色作為卡片左側色帶。
- **可摺疊圓環完成率儀表＋獨立開發統計視覺化面板**：直觀呈現發布率、最新安裝率、分類分佈與月度開發統計。
- **5 套精選強調色主題**：星夜藍、翡翠綠、琥珀金、極光紫、極簡灰（深淺色皆適配）。

## 免卸載覆蓋升級說明
- 固定 `applicationId = "com.npl.appvault"`，已遞增至 `versionCode = 7`、`versionName = "1.8"`。
- 直接將壓縮檔全部檔案覆蓋推送到 GitHub `main` 分支（注意保留 `android/app/src/main/java/com/npl/appvault/` 內的 4 個 `.kt` 檔），待 Actions 編譯完成下載 `AppVault-v1.8.apk` 原地覆蓋安裝即可。
