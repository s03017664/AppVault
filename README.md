# AppVault v2.0 開發總管

## v2.0 核心對齊流程
1. **一登入／開啟即自動連上 Gemini 查各款 Software 最新版本**：
   - 每次開啟時自動掃描手機現裝 APK 版本並呼叫 Gemini 查詢各款 App 的最新版本號、建立日期與介紹用法。
2. **同時顯示「Gemini 最新版本」與「手機現裝版本」**：
   - 每張 App 卡片清晰並列顯示 `Gemini vX.Y` 與 `手機vZ.W`（或 `手機未裝`）。
3. **版本吻合自動打勾、不吻合自動取消打勾（留空）**：
   - 手機實裝版與 Gemini 最新版**吻合** → 自動打勾 `☑ 吻合`。
   - **不吻合**（例如手機現裝 `3.3`，Gemini 最新已到 `3.6`）→ 自動**取消打勾 `☐ 需更新`（留空）**，提醒你去下載更新手機裡的 App；裝好後重新掃描或手動打勾即可。
